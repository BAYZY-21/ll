Q2 Limitations of Normalization in Feature Scaling 3 marks
①
Sensitive to Outliers (Main Limitation)
Normalization compresses all values into [0, 1] based on the min and max. If the dataset contains outliers, these extreme values become the new min/max, causing all other values to be squeezed into a very narrow range — severely distorting the data distribution.
📌 Example: Marks = {26, 27, 30, 35, 38, 39, 40, 48, 50}
Without outlier → 50 maps to 1.0 → 26 maps to 0.0
Add outlier 90 → now 90 maps to 1.0, and 50 maps to only ≈ 0.375
The value 50 (previously max) is now compressed significantly just by adding one outlier!
②
Does NOT produce a standard distribution
Normalization only scales the range — it does not reshape the distribution. If your data is skewed or non-Gaussian, normalization will not fix that. In contrast, Standardization centers data around mean=0 with std=1, which many ML algorithms prefer.
③
Range is fixed only for training data
If new test data contains values outside the training min/max range, the normalized values will fall outside [0, 1], which is unexpected and can cause model errors.
④
Solution → Use Standardization (Z-score) instead
When outliers exist in the dataset, use Standardization: X′ = (X − μ) / σ
Standardization is not affected by outliers because it uses the mean (μ) and standard deviation (σ) rather than absolute min/max values.

Q3 — 1
How do you handle missing values in a data set?
a) Drop missing rows and columns
b) Replace missing values with mean/mode/median
c) Assign a unique category to missing values
d) All of the above
All three strategies are valid. (a) Drop rows — when missing data is minimal. (b) Impute with mean/median (numerical) or mode (categorical). (c) Assign special category — for categorical features. The choice depends on data size and % of missing values.
Q3 — 2
Feature scaling helps to increase the accuracy of the model.
a) True
b) False
TRUE. Feature scaling normalizes the range of features so that no single feature dominates due to its scale. This speeds up convergence in gradient-based algorithms (like neural networks, SVM) and improves accuracy by ensuring fair contribution of all features.
Q3 — 3
What is the use of the LabelEncoder class?
a) It encodes labels with a value between 0 and n_classes
b) It encodes labels with a value between 0 and n_classes-2
c) It encodes labels with a value between 0 and n_classes-1
d) None
LabelEncoder assigns integer labels from 0 to n_classes−1. For example, if you have 3 classes {cat, dog, fish}, they become {0, 1, 2} — that's n_classes−1 = 3−1 = 2 as the maximum value. Use it ONLY for ordered/ordinal categories, not for nominal (unordered) ones like city names.
Q3 — 4
One-hot encoding transforms:
a) each categorical feature with n possible values into n binary features, with only one active
b) each categorical feature with n possible values into n binary features, with a maximum of two active
c) each categorical feature with n possible values into n-1 binary features, with only one active
d) each categorical feature with n possible values into n+1 binary features, with only one active
One-Hot Encoding creates exactly n binary columns for n categories — and exactly one column is 1 (active) per row, all others are 0. Example: Color {Red, Blue, Green} → 3 columns: [1,0,0], [0,1,0], [0,0,1]. Used for unordered (nominal) categories.

DEFWhat is Machine Learning?
Arthur Samuel (1959): "Machine learning is the science of getting computers to act without being explicitly programmed."
Simple definition: ML is about predicting the future based on the past. Or: predicting the unseen based on the already-seen.
ML is a subfield of Artificial Intelligence (AI). Instead of writing explicit rules, the machine learns the rules from data.
TYPESTypes of Machine Learning
📘
Supervised Learning
Training data includes desired outputs (labels).
Goal: Predict output for new input.
  • Classification (Is it A or B?)
  • Regression (How much/many?)
  • Ranking
📗
Unsupervised Learning
Training data does NOT include labels.
Goal: Find hidden patterns.
  • Clustering (k-means, hierarchical)
  • Association Rule Learning
  • Dimensionality Reduction
📙
Reinforcement Learning
Agent learns by trial and error.
Gets rewards/penalties.
No labeled data needed.
Example: autonomous driving, games.

🔢Normalization Formula + Steps (likely to be tested)
X′ = (X − Xmin) / (Xmax − Xmin)
1
Find X_min and X_max
Scan all values in the column to find minimum and maximum.
2
Compute the Range
Range = X_max − X_min
3
Apply formula to the target X
X′ = (X − X_min) / Range → result is in [0, 1]
📐Standardization Formula + Steps
X′ = (X − μ) / σ
μ (mu) = Mean of the column  |  σ (sigma) = Standard Deviation
After standardization: Mean = 0, Std Dev = 1
Standard Deviation formula: σ = √[ Σ(xᵢ − μ)² / n ]
Example: dataset {4,8,6,5,3} → μ = 5.2 → variance = 2.56 → σ ≈ 1.6

📚Quick Definitions — Short Answer Ready
ML
Machine Learning: a subfield of AI that enables computers to learn from data without explicit programming. "Predicting the future based on the past."
SL
Supervised Learning: training with labeled data (input→output known). Used for prediction. Sub-types: Classification, Regression.
UL
Unsupervised Learning: training with unlabeled data. Finds hidden patterns. Sub-types: Clustering, Association, Dimensionality Reduction.
OUT
Outlier: an extreme value that falls outside the normal range. Main cause of normalization failure. Solution: use Standardization instead.
NORM
Normalization (Min-Max Scaling): rescales values to [0,1]. Best when standard deviation is small. Sensitive to outliers.
STD
Standardization (Z-score): rescales to mean=0, std=1. Use when outliers exist. Not bounded to a fixed range.
📊Standardization — Worked Example (from lecture)
Dataset: {4, 8, 6, 5, 3} — Find standard deviation step by step
Step-by-step: Standard Deviation
①Mean μ = (4+8+6+5+3) / 5 = 26/5 = 5.2
②Deviations squared:
(4−5.2)² = (−1.2)² = 1.44
(8−5.2)² = (2.8)² = 7.84
(6−5.2)² = (0.8)² = 0.64
(5−5.2)² = (−0.2)² = 0.04
(3−5.2)² = (−2.2)² = 4.84
③Variance = (1.44 + 7.84 + 0.64 + 0.04 + 4.84) / 5 = 14.8/5 = 2.96
④Standard Deviation σ = √2.96 ≈ 1.72
σ = √[ Σ(xᵢ − μ)² / n ] = √2.96 ≈ 1.72
After standardization all values in a column will have: Mean = 0 and Std Dev = 1.
Formula: X′ = (X − μ) / σ  →  For X=4: X′ = (4 − 5.2) / 1.72 ≈ −0.698

🎮Reinforcement Learning — Key Concepts
Agent
The learner / decision-maker that interacts with the environment.
Environment
Everything the agent interacts with. Provides states and rewards.
State
A specific situation the agent finds itself in at a given moment.
Action
All possible moves the agent can make in the current state.
Reward
Feedback from the environment based on the action taken. Goal: maximize cumulative reward.
Real Example
Autonomous driving: car (agent) learns to drive (actions) on roads (environment) to avoid crashes (reward/penalty).
Key difference from Supervised: No labeled training data. The agent learns by trial and error — taking actions, observing outcomes, and adjusting to maximize rewards.
